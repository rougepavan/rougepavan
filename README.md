Check out a few of my projects that showcase my work in **full-stack development** and **frontend design**:

- Product catalog with filtering and search  
- Integration with **Stripe** for secure payments  

#### 2. **✍️ Blogging Platform with Authentication (Full-Stack)**  
A blogging platform where users can create, edit, and delete their posts. Includes authentication for secure login.  
**Tech Stack**: React, Node.js, Express.js, MongoDB  
**Features**:  
- User registration, login, and JWT-based authentication  
- CRUD operations for managing blog posts  
- Admin panel for managing users and posts  

#### 3. **✅ Task Management Application (Frontend)**  
A simple and intuitive task management application where users can organize their tasks based on priority and deadlines.  
**Tech Stack**: React, Redux, TailwindCSS, JavaScript  
**Features**:  
- Task creation, editing, and deletion  
- Task categorization (To-Do, In Progress, Completed)  
- Responsive and interactive UI  

#### 4. **🌦️ Weather Dashboard (Frontend)**  
A weather forecasting app that fetches live weather data from an external API.  
**Tech Stack**: React, OpenWeather API, JavaScript  
**Features**:  
- Real-time weather data based on user’s location  
- Search functionality for any city in the world  
- Dynamic display of weather details  

#### 5. **📚 Library Management System (Backend)**  
A library system for managing books, users, and transactions.  
**Tech Stack**: Spring Boot, MySQL  
**Features**:  
- Admin panel to manage book entries  
- User functionality to borrow and return books  
- RESTful API for managing library resources
